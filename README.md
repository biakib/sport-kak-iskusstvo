# Спорт как искусство

Самостоятельная статическая версия сайта проекта Ивана Егорова для публикации через GitHub Pages.

## Публикация

Сайт публикуется из каталога `site/` при каждом пуше в ветку `main`.

## Структура

- `site/index.html` — разметка страницы;
- `site/styles.css` — стили и адаптивная версия;
- `site/app.js` — интерактивные биографии, анимации появления и прогресс страницы;
- `site/assets/` — локальные шрифты и архивные файлы первоначальной сборки;
- `site/images/` — изображения проекта;
- `.github/workflows/pages.yml` — публикация на GitHub Pages.

`build-cloudflare.sh` сохранён только как архивный скрипт импорта прежней версии. Он больше не участвует в публикации.
