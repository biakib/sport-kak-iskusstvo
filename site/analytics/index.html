Внутренний инструмент команды

Sport as Art Analytics

Сервис собирает статистику собственных социальных площадок проекта «Спорт как искусство», чтобы команда могла оценивать публикации и готовить еженедельные отчёты.

Подключение YouTube

Владелец канала предоставляет доступ через официальную страницу Google. Приложение запрашивает только чтение данных канала и отчётов YouTube Analytics: просмотров, времени просмотра, средней длительности, подписок и реакций.

Этот модуль не загружает, не редактирует и не удаляет видео. Подключение доступно по персональной ссылке администратора; публичной регистрации нет.

Как используются данные

Показатели обрабатываются в Cloudflare и используются для внутренних отчётов команды. Подготовленный отчёт может быть передан назначенному получателю через Telegram-бот статистики. Он не публикуется автоматически в открытом канале.

Сервис использует YouTube API Services. Авторизация выполняется на сайте Google; пароль Google не передаётся сервису.

Управление доступом
