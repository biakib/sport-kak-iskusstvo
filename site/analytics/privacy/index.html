Политика конфиденциальности

Политика относится к приложению Sport as Art Analytics проекта «Спорт как искусство». Контакт по вопросам конфиденциальности и удаления данных: ledvanzep@gmail.com.

Данные YouTube

После разрешения владельца приложение получает сведения о канале, показатели подписчиков и просмотров, данные публикаций и агрегированные отчёты YouTube Analytics. Доступ предоставляется только для чтения. Пароль Google не запрашивается и не сохраняется приложением.

Цели использования

Полученные данные используются для анализа собственных публикаций и подготовки отчётов владельцу канала и уполномоченным им участникам команды. Данные не продаются, не используются для рекламного таргетинга и не используются для обучения обобщённых моделей искусственного интеллекта. Техническая обработка может выполняться поставщиками услуг, необходимыми для работы приложения и подготовки запрошенного отчёта.

Использование и передача информации, полученной через Google API, соответствуют Google API Services User Data Policy, включая требования Limited Use. Данные не публикуются в открытом доступе без указания владельца.

Отзыв доступа и удаление

Владелец может отозвать разрешения в настройках доступа Google. Чтобы удалить сохранённые приложением сведения, направьте запрос на ledvanzep@gmail.com с указанием канала. Перед удалением может потребоваться подтверждение полномочий владельца. Копиями отчётов, уже полученными владельцем, он управляет самостоятельно.

Google и YouTube

Приложение использует YouTube API Services. Ознакомьтесь также с Политикой конфиденциальности Google и Условиями использования YouTube.
